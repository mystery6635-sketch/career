## 사용자 결정이 필요한 것

1. **A4 한 장 요구 vs 최대 길이 결과(2쪽)**: spec FR-022와 contracts/copy-and-print.md의 "한도를 모두 채워도 한 장" 요구가 지금 값(문장 120자, 연결 항목 6개, 설명 3문장)으로는 맞지 않는다. 실제 Mock 결과 5개는 모두 한 장이다. 선택지: (a) 문장 한도를 줄인다(예: 한 문장 120자 → 80자 안팎, 값은 다시 측정 필요), (b) 한도는 두고 "최악의 경우 두 장"을 허용하도록 FR-022를 고친다, (c) 현재 상태를 유지하고 실제 LLM 결과가 평소 한 장인지 Phase 7에서 측정한 뒤 결정한다.
2. 키워드 카드의 "연결된 입력 항목" Tag 표시(T069 승인 대기)는 Mock 화면에 이미 들어 있다.

- 입력·결과 화면의 부제(design §3.2·§3.3에 "부제"가 있으나 문구가 없음): 넣지 않았다.
- 이용 흐름 4단계 카드에는 단계 이름만 있고 설명 문장은 없다(design §2에 설명 문구 없음).

### 추가 측정 (T063, 2026-10-11)

문장 한도만 줄이는 선택지 (a)로는 한 장에 들어가지 않는다. 최대 길이 Mock에서 문장 길이를 120 → 80 → 60 → 40자로 줄여 `page.pdf` 쪽수를 쟀으나 모두 2쪽이었다(40자에서도 내용 높이가 인쇄 가능 영역보다 약간 큼). 쪽수는 문장 길이보다 연결 항목 6개 줄, 항목 상자 9개, 설명 문장 수가 좌우한다. 따라서 한 장 보장에는 문장 한도 외에 연결 항목 수·설명 문장 수 조정 또는 (b) "최악의 경우 두 장 허용"이 필요하다. 사용자 결정 전까지 T063은 완료 처리하지 않는다.
